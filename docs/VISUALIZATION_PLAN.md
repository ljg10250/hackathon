# 한눈에 보기 구현 범위

2026-10-31 사용자 요청에 따라 수치의 의미를 설명하고 다섯 번째 메뉴 `/visualizations`를 추가한다.

1. 기존 고용률·자치구·직종 차트에 값으로 계산하는 짧은 해석문을 제공한다. 현재 수준과 전년 동기 변화를 구분하며 원인·개인 확률을 추정하지 않는다.
2. 수도권 비교는 서울·경기·인천·전국4지역×23분기92개를 별도 검증 버전으로 준비한다. 기존 서울–전국46행과 API는 유지한다.
3. 자치구 원 표/기초표의275개 값·연령·항목단위를 검증한다. 분기와 반기를 섞지 않는다.
4. 공식2025년2분기 경계를25구 코드·명칭으로 대조하고 시각화용40m 단순화와 북쪽 위 동일축척 SVG를 생성한다. 지도 클릭·키보드·선택상자·확대를 제공한다.
5. 자치구×반기25×11 색상표를 제공한다. 지도와 표의 색 범례는 모든 시점에 고정하고 미확인은 회색으로 구분한다. 선택 구·기간의 설명·추이·근무지 공고 탐색을 연결한다.
6. 타입·계산·실제DB/API·RLS·PC/모바일·키보드·자동접근성 검증 후 기존 무료 Worker에 배포하고 공개 URL을 검사한다.

고용률과 취업자 수·취업률·실업률의 정의 및 단위는 다르다. 이번은 검증된15~29세 고용률 중심이다. 취업자 수를 고용률과 같은 축으로 그리거나 미확인 연령의 실업률을 공개하지 않는다.

후속 선택 기능은 수준/변화 산점도와 공고조건 확인가능 비율이다. 이번 핵심 범위에 포함하지 않았다. 통근시간·일자리 접근성 점수·취업효과 예측을 생성하지 않는다.

현재 결과와 단계 판정은 reports/VISUALIZATION_IMPLEMENTATION_REPORT.md를 따른다.
