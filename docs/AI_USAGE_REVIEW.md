검사 중 생성한 합성 오류·경계값은 테스트 fixture이며 실제 통계·공고와 구분한다. 수치·설명은 원 자료와 산식으로 확인하고, 테스트 통과를 사용자 만족도나 취업 효과가 검증된 것으로 표현하지 않는다.

현재 사용자 대상 탐색시간·성공률·취업 성과 검증은 수행하지 않았다. 모델·프롬프트·토큰 사용량 자체를 성능이나 심사 가점의 증거로 제시하지 않는다.

## 시각화에서 추가로 발견·검증한 사례

- KOSIS 공통 단위 ‘천명’과 선택 항목 ‘고용률(%)’의 불일치를 발견했다. T00/T12 항목, 정의·산식, 기초표275개 값까지 대조해 항목 단위를 구분했고 원 응답을 보존했다.
- 실제 지도에서 이름 중앙을 누르면 인접 구가 선택되는 사례를 발견했다. 라벨을 구 내부 여유 공간에 중앙 배치하고 이름 클릭을 연결했다. PC 마우스·모바일 터치로25구씩50회 검사했다.
- 출처를6개로 고정한 과거 검사 가정이 신규 검증 버전에 맞지 않았다. 필수 출처의 보존·고유성·메타데이터를 검사하도록 바꾸고 추천27항목을 재검증했다.

이 사례의 초기 실패 기록과 최종 공개 통과 결과는 reports/VISUALIZATION_IMPLEMENTATION_REPORT.md를 따른다.
