## 2026-10-31 현재 실행 기준

- 2단계 공개 배포 완료: https://seoul-youth-job-compass.ljg10250000.workers.dev 에서 초기 HTTP 17항목 통과 (`reports/stage2_public_20261031.json`). 이전 인증 차단 기록은 과거 결과다.
- 새 가중치의 사용자 확정은 이번 세션의 답변이며, 과거 문서에 숫자가 있었다고 소급하지 않는다.
- 조건 목록의 여러 값은 OR, 서로 다른 항목은 AND다. 지역·직종·고용형태·근무일수·필수 공고 경력 표기는 원본 값과 정확 비교한다. 근무일수는 ‘최대 N일’이 아닌 선택한 주 N일 값이다.
- 임금 조건은 `{type:"월급",minimum:3000000}`처럼 원 단위 최소 기준이다. 기재 최소≥기준은 충족, 기재 최대<기준은 불일치, 범위가 걸치거나 상한만 미기재인 채 최소가 기준 미만이면 미확인이다. 단위가 다르면 미확인. 연봉·월급 환산은 적용하지 않는다.
- 미선택 선호는 분모에서 제외한다. 미확인은 확인 점수 0, 가능한 최대에는 해당 가중치를 더한다. 선호가 없으면 점수와 표시값이 null이다.
- DB numeric으로 반올림 전 점수를 정렬하고 화면에는 소수 첫째 자리 ‘확인 ~ 최대’를 표시한다. 필수 불일치 행에는 선호 점수를 계산하지 않는다.
- 관련 직종은 증거 URL·검증시각을 갖춘 명시적 6자리 방향 관계만 사용한다. `hierarchy`는 절대 사용하지 않는다. 현재 직종 대안은 `no_verified_related_occupations`와 빈 결과를 반환한다.
- 대안에는 선호 지역·직종 둘 다 필요하다. 탭 간 중복은 허용하며 각 결과는 기존 jobs PK로 중복이 없다. 인접성·공고 수 가산점은 없다.
- 로그인·개인정보·검색 기록 저장·추적 기능은 추가하지 않았다. 기존 테이블·RLS·공개 쓰기 차단을 유지했다.
