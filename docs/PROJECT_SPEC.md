# 현재 서비스 명세

기준일:2026-11-01. 대상은 서울 청년 구직자이며, 지역 고용 흐름과 개별 공고의 기재조건을 함께 비교하도록 돕습니다. 사용자 효과는 미검증입니다.

## 화면

| 경로 | 기능 |
| --- | --- |
| / | 동일15~29세·분기의 서울/전국 고용률, 격차%p, 전년 동기 변화 |
| /visualizations | 기본 서울 지도·반기 변화표, 수도권4지역 분기 비교 |
| /districts | 25구 고용률 비교와 선택 구의11반기 추이 |
| /occupations | KECO2025 중분류35개, 전체연령·등록관서 기준 구인/구직과 해당 분류 공고 탐색 |
| /jobs | 지역·직종·공고 경력·제목 검색,10/20/50건 페이지 처리 |
| /jobs?mode=recommend | 필수/선호 조건, 점수 범위와 근거, 전체/대안 결과 |
| /jobs/:id | 기재조건·날짜·공식 포털 검색 안내, 검색 조건과 페이지를 유지한 복귀 |

주 메뉴는5개입니다. 삭제한 발표 기능은 제공하지 않습니다. 별도의 자체 MCP 서버는 운영하지 않으며 실제 공개 서비스는 자체 REST API를 사용합니다.

## 추천 규칙

- 2026-10-31 사용자가 확정한 가중치: 직종35·지역25·임금20·근무일수10·고용형태10. 관련직종은 검증된 관계에 한해17.5점이나 현재 관계0개입니다. 계층 연결은 관련성이 아닙니다.
- 필수 조건을 먼저 검사합니다. 명백 불일치는 제외하고 미확인은 조건 확인 필요로 분리합니다. 배열 내 OR·항목 간 AND입니다.
- 선호 미선택 항목은 분모에서 제외하고 비례 환산합니다. 선호가 없으면 점수는 null입니다. 미확인은 확인 점수에는 더하지 않고 가능한 최대에만 더합니다.
- 임금은 같은 유형·원 단위 최소 기준으로 비교합니다. 기재 최소≥기준은 충족, 기재 최대<기준은 불일치, 범위가 걸치거나 비교 불가능하면 미확인입니다. 연봉/월급을 환산하지 않습니다.
- 근무일수는 선택한 주 N일 값과 정확 비교합니다. 경력은 필수 조건으로만 사용할 수 있습니다.
- 확인 점수(반올림 전) 내림차순 → 선택 선호 미확인 수 오름차순 → 등록일 최신순 → 안정 내부ID 순으로 정렬합니다. 화면은 소수 첫째 자리의 확인 점수~가능 최대를 표시합니다.
- 전체 추천은 모든 필수 충족 공고입니다. 지역 대안은 희망 직종 유지·선호 지역 밖 서울 구, 직종 대안은 희망 지역 유지·검증된 관련직종만 조회합니다. 대안에는 선호 지역·직종이 모두 필요하며 필수 조건을 완화하지 않습니다.
- 탭 간 중복은 허용하고 각 결과 내 같은ID는 중복하지 않습니다. 인접성·공고 수 가산점은 없습니다. 일반 검색의 score는 null이며 추천 점수는 취업확률이 아닙니다.

## 데이터와 화면 원칙

- 고용률은15~29세·거주지, 직종 행정통계는전체연령·등록관서, 공고는근무지 기준으로 구분합니다. 분기·반기·월을 섞거나 구 평균을 서울 값으로 사용하지 않습니다.
- 선그래프는 기본25~75%이되 실제값을 모두 포함하도록 확장합니다. 막대는0기준, 지도색범례는 전시점 동일입니다. 결측은 선을 끊고 실제0은 유지합니다.
- 모든 차트·지도·변화표 아래의 해석은 표시된 기간·지역·직종에 맞춰 갱신합니다. 지역 격차는%p, 직종 비중은 표시된 합계 기준, 변화표는 처음/마지막 반기의 쌍이 확인된 구만 집계합니다.
- 네이비·청록, 서울#3676C5·전국#0D9488, Pretendard·본문16px, PC상단/모바일하단 메뉴와 키보드 접근·데이터표를 유지합니다.
- 출처 필수정보·모집상태 미확인 안내를 유지합니다. 회원가입·개인정보 입력·검색 이력 영속 저장·방문자 추적을 추가하지 않습니다.

완료 근거와 검증 범위는 [검증 기준](../reports/VALIDATION.md), 남은 데이터 보류는 [데이터 감사](../DATA_AUDIT.md)를 따릅니다. 실제 제출·최종 심사 결과는 확인하지 않았습니다.
