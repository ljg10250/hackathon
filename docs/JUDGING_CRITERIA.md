# 사용자 제공 심사 기준 · 2026-10-31

문제 정의·기획20, 공공데이터 활용35, 서비스 구현·AI 활용20, 인문·사회적 가치15, 발표·전달력10으로 기본100점. 공공데이터를 조회·가공하는 자체 MCP/API를 직접 구현하고 실제 서비스나 도구가 호출하는 시연은 최대+5점이며 최고105점이다. 기존 OpenAPI 단순 호출만으로는 해당하지 않는다. 가산점 확정은 심사 결과다.

동점은 공공데이터→문제 정의→구현·AI 점수 순으로 비교하고 여전히 같으면 공동수상이다. CSV·XLSX 활용은 감점 사유가 아니며 서비스 내 AI는 필수가 아니다. AI 활용 과정과 결과 검증이 평가 대상이다.

필수 제출 항목: 팀 이름(개인 참가자는 본인 이름), 대표 이메일, 한 줄 소개, 배포URL, 사용 공공데이터 출처·기준 시점. 선택 항목: 발표 자료 링크, 썸네일, 작품 설명서, AI 활용 노하우. 현재 팀/대표 정보를 임의 작성하지 않는다. 공식 제출 포털·마감·발표시간·파일형식/용량은 이 안내로 확인되지 않았다.

정확한 기간·지역·연령·정의·단위 비교와 데이터가 진단/비교 결과를 직접 만드는 기능을 우선한다. 관측과 추정·합성자료를 구분하고 미구현 기능·미검증 효과를 완료로 표현하지 않는다. 개인정보와 키를 보호한다.

이 문서는 사용자가 대화에서 제공한 기준을 작업용으로 정리한 것이며, 별도 공식 요강 문서를 확보했다고 뜻하지 않는다.
