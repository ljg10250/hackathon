# 문제와 데이터 근거

서울 청년 구직자가 지역 고용 흐름과 공고의 기재조건을 함께 이해·비교하도록 돕는 서비스입니다. 여러 자료의 기준 차이·미확인 조건 때문에 탐색이 어렵다는 것은 사용자 가설이며, 탐색시간 감소나 취업 효과를 측정하지는 않았습니다.

## 관측한 사실

- 2026년3분기15~29세 고용률은 서울47.1%·전국44.1%, 차이는3.0%p입니다. 전년 같은 분기의49.8%·45.3% 대비 각각2.7%p·1.2%p 하락했습니다. 전국은 서울을 포함합니다.
- 2026년9월 서울 등록 노동관서의 KECO35개 합계는 신규구인18,299명·신규구직59,668건입니다. 전체연령 행정통계이며 개인 경쟁률이 아닙니다.
- 서울 근무지 공고는2026-08-31~10-29 등록 스냅샷입니다. 구인인원·공고 행수·현재 모집 중인 수는 서로 다릅니다.

고용률만으로 구직 어려움의 원인·지역의 우열·개인 취업 가능성·통계적 유의성을 판단하지 않습니다. 비취업자의 비율이 실업률인 것도 아닙니다.

## 기능 연결

같은 기준의 고용률 비교 → 관심 구의 반기 흐름/직종별 월간 등록 현황 → 해당 근무지·검증된 분류의 공고 탐색 → 필수/선호 조건 비교 → 공식 포털에서 모집 여부 확인의 흐름입니다. 분기·반기·월과 거주지·등록관서·근무지 기준을 합치지 않습니다.

직종 탐색은 공식 코드+명칭323쌍의 계층 연결만 사용하고 미검증235쌍은 제외합니다. 계층은 관련성·직무 전환 가능성·추천 가산점의 근거가 아닙니다.

근거: [고용률 검증](../reports/kosis_employment_verification_20261031.json), [공식 응답](../data/metadata/kosis_employment_20261031.json), [데이터 감사](../DATA_AUDIT.md). 후속 사용자 검증에서는 동일 공고 탐색 과제의 완료 여부·시간·오해를 기록하고 참가자/과제/환경을 공개해야 합니다. 소수 사례를 전체 청년의 효과로 일반화하지 않습니다.
