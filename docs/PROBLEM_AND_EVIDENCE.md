# 문제 정의와 근거

대상은 서울의 청년 구직자다. 기본 통계 연령은 15~29세이며 채용공고는 전체 연령 스냅샷이다. 공고가 청년 전용이라는 주장은 하지 않는다.

서비스 목표는 지역 고용 흐름과 직종별 등록 현황을 확인한 뒤 개인의 기재 근무조건에 맞는 공고를 비교하도록 돕는 것이다. 탐색 부담 감소는 목표이며 측정된 효과가 아니다.

## 자료로 확인한 사실

- 원 표 대조를 통과한 2026년 3분기 고용률은 서울47.1%, 전국44.1%다. 서울−전국은 +3.0%p이며 전국은 서울을 포함한다.
- 같은 표의 전년 같은 분기 값은 서울49.8%, 전국45.3%다. 전년 동기 변화는 각각 −2.7%p, −1.2%p다. 계절이 다른 분기와의 변화로 대체하지 않는다.
- 이 결과만으로 구직 어려움의 원인·통계적 유의성·개인 취업 가능성을 판단하지 않는다. 비취업자의 비율이 실업률을 뜻하지도 않는다.
- 2026년9월 서울 등록 노동관서의 KECO35개 중분류 합은 신규구인18,299명·신규구직59,668건이다. 전 연령·등록 행정통계이며 청년만의 수급이나 개인 경쟁률이 아니다.
- 공고는 등록일2026-08-31~10-29의 근무지 서울 스냅샷이다. 실시간 모집 여부는 미확인이다. 통계의 구인인원과 공고 행수를 동일시하지 않는다.

## 기능과의 연결

고용률 비교(분기·거주지) → 관심 자치구(반기·원 표 보류 안내) 또는 직종별 등록 현황(월·전체 연령) → 해당 근무지·검증된 분류 공고 → 기재조건 비교 → 공식 포털에서 모집 여부 확인.

직종 탐색에는 공식 코드+명칭 검증323쌍의 계층 연결만 사용한다. 235쌍은 제외한다. 계층 관계는 관련성·직무 전환 가능성·추천 가산점의 근거가 아니다.

## 추가로 확인할 사용자 가설

‘여러 자료의 기준 차이와 공고의 미확인 조건을 이해하기 어렵다’, ‘조건을 유지하며 공고를 비교하면 탐색이 수월해진다’는 사용자 가설이다. 현재 직접 인터뷰·사용성 조사로 확인하지 않았다.

후속 탐색적 사용성 확인은 실제 참가자에게 같은 공고 찾기 과제를 수행하게 하고 완료 여부·소요시간·잘못 이해한 조건을 기록한다. 기존 탐색 방법과 앱의 순서를 바꾸어 학습 영향을 줄이고 결과를 참가자 수·과제·환경과 함께 공개한다. 소수 사례를 전체 청년의 효과나 인과효과로 일반화하지 않는다. 이름·연락처·사이트 방문 기록을 수집할 필요는 없다.
