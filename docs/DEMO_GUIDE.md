## 약3분 시연 초안 (공식 발표시간 미확인)

1. 고용현황에서 동일15~29세·분기 기준의 서울47.1%, 전국44.1%, 격차+3.0%p와 전년 동기변화−2.7%p/−1.2%p를 본다. 전국은 서울을 포함하고 인과효과/개인확률은 아님을 설명한다. 비교분기2025-Q3을 선택해49.8%/45.3%와+4.5%p를 확인하고 연도선택을2025로 바꿔7개분기를 본다.
2. 자치구에서 반기·구를 선택해25구 막대와11반기 추이를 본다. 거주자기준 고용률과 근무지 공고 링크의 기준이 다름을 설명한다.
3. 직종분석에서2026년9월/전체연령/등록지방노동관서 기준을 설명한다. 구인18,299명·구직59,668건의 단위와 독립축을 보여주고 한직종의 명/건 산식을 확인한다. 경영·행정·사무직을 선택해 ‘이 직종 분류의 검증된 공고 탐색’을 누른다. 계층연결323쌍만 사용하고 관련직종 추천은 아님을 설명한다.
4. 일자리찾기에서 지역과 원본직종명을 선택하고10건씩 조회한다.2페이지→상세→돌아가기로 조건/페이지 유지와 기재마감/실제모집상태 구분을 보여준다.
5. 조건추천에서 직종/지역/임금/근무일수/고용형태를 선택한다. 필수먼저검사·미확인분리·미선택비례환산·확인점수~가능최대·계산근거를 설명한다.
6. 지역대안은 희망직종 유지,직종대안은 검증된 관계가0개라보류,필수지역/직종은 완화하지 않음을 보여준다.점수는 합격/취업확률이 아니다.

## 자체 가공API 실제 호출 근거

`reports/api_demo_20261031.json`에 공개주소에서 실행한6개GET요청의 전체URL·시각·HTTP상태·응답·계산대조를 보존했다.
공식외부 MCP호출만이 아닌 이 프로젝트의 `/api/occupations`·`/api/recommendations` 가공결과다.
직종구인배수는 명/건 나눗셈,추천은 선택가중치와 미확인처리를 독립TypeScript계산과 DB결과로 대조했다.

```text
node scripts/capture_api_demo.mjs https://seoul-youth-job-compass.ljg10250000.workers.dev reports/api_demo_NEW.json
```

직접지원URL·실시간모집상태·교통시간·AI취업확률·미검증관련직종을 구현했다고 말하지 않는다.
회원가입/프로필/검색기록저장/방문자추적이 없고 공개DB쓰기 차단을 유지한다.

## 제출 전 확인할 항목

- 공식요강의 제출형식·파일수/용량·시연영상/발표자료 요구사항·가산점판정조건·마감.
- 참가팀명·팀원/대표자·연락정보 등 실제 신청서 필수값. 현재 프로젝트 자료에서 참가자 정보를 확정하지 않았으므로 임의 작성하지 않는다. 필수5개·선택4개 항목과 배점은 docs/JUDGING_CRITERIA.md에 사용자 제공 기준으로 정리했다.
- 공개링크·후보ZIP·candidate_manifest의 SHA256·검사보고서·API실행로그를 대조한다.
- 원자료의 남은 보류를 공개적으로 설명한다. 가산점은 심사자의 판단이며 확보했다고 확정하지 않는다.
- 현재 후보는 로컬 준비본이다. 외부포털에 제출하거나 메시지/이메일로 전송한 결과가 아니다.
