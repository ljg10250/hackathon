# 6단계 시연·제출 준비

2026-10-31에 공개사이트·자체API 실제 호출로그와 시연 안내를 준비했다. 이전 로컬 후보ZIP은 이후 사용자 요청으로 삭제했으며 현재 제출물로 안내하지 않는다.

- 호출 근거: [API6요청·계산 대조](api_demo_20261031.json).
- 시연: [사이트·자체API 안내](../docs/DEMO_GUIDE.md).
- 제출 항목·배점: [사용자 제공 기준](../docs/JUDGING_CRITERIA.md).
- 최종 확인: 공개URL/API 정상 응답, 출처·기준 시점, 참가자 필수정보, 운영진의 제출형식/마감.

실제 외부 제출 여부·최종 가산점·사용자 효과는 이 작업에서 확인하지 않았다. 현재 구현과 검사 범위는 [VALIDATION.md](VALIDATION.md)를 따른다.
