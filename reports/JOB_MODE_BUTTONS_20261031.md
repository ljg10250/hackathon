## 변경

기존 일반 검색의 밑줄 글자·추천 전환 링크와 추천 화면의 본문 링크를 공통 `web/JobModeSwitch.tsx`로 바꿨다. 두 화면에 ‘일반 검색’과 ‘조건 추천·대안’을 모두 표시한다.

- 각 영역에2px 테두리·배경·넉넉한 패딩·그림자를 적용했다. PC에서는 나란히,600px 이하에서는 세로로 표시한다.
- 선택한 방식은 진한 청록 배경·흰 글자·체크와 ‘선택됨’, `aria-current="page"`로 구분한다.
- 비선택 버튼은 흰 배경과 진한 테두리, 이동 화살표로 표시한다. 테두리#6685a3과 흰 배경의 대비는3.85:1, 선택 배경#08766d과 흰 글자는5.49:1이다.
- 짧은 설명과 호버·키보드 초점을 제공한다. 페이지 이동이므로 실제 요소는 링크를 유지한다. 양방향 전환에서 지역·원본 직종 선택을 보존한다.

수정 파일은 `web/pages.tsx`, `web/Recommendations.tsx`, `web/style.css`와 신규공통컴포넌트다. Worker API·추천 계산·DB·데이터를 변경하지 않았다. 원래 파일은 이 작업 폴더의 implementation/job_mode_buttons_20261031/*.before에 보존했다.
